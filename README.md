# Sentiment Web Analysis

##  Overview

Sentiment Web Analysis is a web application developed using Python, Flask, and TextBlob. It analyzes the sentiment of user-entered text and classifies it as Positive, Negative, or Neutral.

##  Features

- Analyze text sentiment
- Positive, Negative, and Neutral classification
- Simple web interface
- Fast sentiment prediction

##  Technologies Used

- Python
- Flask
- TextBlob
- HTML

```
sentiment-web-analysis/

```

##  Installation

1. Clone the repository

```bash
git clone https://github.com/annliza-reji/sentiment-web-analysis.git
```

2. Install dependencies

```bash
pip install flask textblob
```

3. Run the application

```bash
python app.py
```
